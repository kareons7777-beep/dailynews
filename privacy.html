개인정보처리방침

시행일: 2026년 11월 13일

1. 이 앱은 무엇인가요

DailyNews는 채널 운영자 본인이 자신의 컴퓨터에서 실행하는 개인용 도구로, 매일 만든 뉴스 쇼츠 영상을 운영자 본인의 유튜브 채널에 올립니다. 다른 사람이 가입하거나 로그인하는 서비스가 아닙니다.

2. 접근하는 Google 사용자 데이터

  • 요청 권한: YouTube 동영상 업로드(https://www.googleapis.com/auth/youtube.upload) 하나뿐입니다.
  • 이 권한으로 운영자 채널에 영상과 제목·설명·태그를 올리는 일만 합니다.
  • 구독자, 시청 기록, 댓글, 이메일, 연락처 등 다른 Google 데이터는 읽지 않습니다.

3. 저장과 보관

  • 로그인 후 발급되는 인증 토큰은 운영자 본인 컴퓨터의 파일에만 저장되며, 외부 서버로 보내지 않습니다.
  • 업로드 결과(영상 ID, 업로드 시각)는 같은 영상을 두 번 올리지 않도록 운영자 컴퓨터에 기록합니다.
  • 토큰은 운영자가 파일을 지우거나 Google 계정 설정(보안 → 타사 앱 액세스)에서 권한을 해제하면 즉시 사용할 수 없게 됩니다.

YouTube API 서비스 사용

DailyNews는 YouTube API 서비스를 사용합니다. DailyNews를 사용하는 것은 YouTube 서비스 약관에 동의하는 것이며, Google의 데이터 처리에는 Google 개인정보처리방침이 적용됩니다.

DailyNews의 접근 권한은 언제든지 Google 보안 설정의 타사 앱 액세스 페이지에서 해제할 수 있습니다. 해제하면 저장된 인증 토큰은 더 이상 사용할 수 없습니다.

DailyNews는 브라우저 쿠키 등 사용자의 기기에 정보를 저장하거나 읽지 않습니다. 인증 토큰은 운영자 컴퓨터의 파일에만 저장됩니다.

4. 제3자 제공

Google 사용자 데이터를 판매하거나 제3자에게 제공하지 않으며, 광고나 분석 목적으로 사용하지 않습니다. DailyNews의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 영상에 담기는 정보

영상은 공개된 언론 보도의 제목을 바탕으로 요약하며, 공인이 아닌 개인의 신원은 다루지 않습니다. 대본·음성·진행자 그림은 AI로 생성하고, 각 영상에 AI 생성 콘텐츠임을 표시합니다.

6. 문의

이 방침에 대한 문의는 DailyNews 유튜브 채널의 '정보' 탭에 안내된 연락처로 보내 주세요.

English summary

DailyNews is a personal tool run by the channel owner on their own computer. It uses the YouTube API Services with a single scope (youtube.upload) only to upload the owner's videos, titles, descriptions and tags to the owner's own channel. It does not read any other Google user data. The OAuth token is stored only in a local file on the owner's computer and is never sent to any other server, sold, or shared. By using DailyNews you agree to the YouTube Terms of Service; see also the Google Privacy Policy. Access can be revoked at any time via the Google security settings page. Contact: see the "About" tab of the DailyNews YouTube channel.
